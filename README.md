# Genesis

Suite creativa con IA para **Windows, macOS y Linux**: editor de video, imagen, audio, documentos,
hojas de cálculo y presentaciones, con tus cuentas de IA o con IA local sin cuentas.

## Descargar

| Sistema | Descarga directa |
| --- | --- |
| Windows 10 y 11 | [Descargar (.exe)](https://genesis-app-amber.vercel.app/descargar/windows) |
| macOS Apple Silicon (M1, M2, M3, M4) | [Descargar (.dmg)](https://genesis-app-amber.vercel.app/descargar/macos-arm) |
| macOS Intel | [Descargar (.dmg)](https://genesis-app-amber.vercel.app/descargar/macos-intel) |
| Linux: Ubuntu, Debian, Mint | [Descargar (.deb)](https://genesis-app-amber.vercel.app/descargar/linux-deb) |
| Linux: Fedora, openSUSE | [Descargar (.rpm)](https://genesis-app-amber.vercel.app/descargar/linux-rpm) |
| Linux: cualquier distribución | [Descargar (AppImage)](https://genesis-app-amber.vercel.app/descargar/linux-appimage) |

Siempre descargan la última versión. El `.msi` de Windows y `SHA256SUMS.txt` están en
[la última versión](https://github.com/UreckChan/genesis-app/releases/latest).

> **Instalación bajo su propio riesgo.** Genesis es un proyecto independiente y sus instaladores no
> llevan certificado comercial de editor, así que Windows y macOS mostrarán un aviso la primera vez.
> Descarga solo desde aquí y comprueba el archivo con `SHA256SUMS.txt`.
