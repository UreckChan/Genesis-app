# Genesis

Suite creativa con IA para **Windows, macOS y Linux**: editor de video, imagen, audio, documentos,
hojas de cálculo y presentaciones, con tus cuentas de IA o con IA local sin cuentas.

## Descargar

| Sistema | Descarga directa |
| --- | --- |
| Windows | [Genesis-Windows-x64.exe](https://github.com/UreckChan/genesis-app/releases/latest/download/Genesis-Windows-x64.exe) |
| macOS Apple Silicon (M1, M2…) | [Genesis-macOS-AppleSilicon.dmg](https://github.com/UreckChan/genesis-app/releases/latest/download/Genesis-macOS-AppleSilicon.dmg) |
| macOS Intel | [Genesis-macOS-Intel.dmg](https://github.com/UreckChan/genesis-app/releases/latest/download/Genesis-macOS-Intel.dmg) |
| Linux (Ubuntu, Debian, Mint) | [Genesis-Linux-x64.deb](https://github.com/UreckChan/genesis-app/releases/latest/download/Genesis-Linux-x64.deb) |
| Linux (cualquier distribución) | [Genesis-Linux-x64.AppImage](https://github.com/UreckChan/genesis-app/releases/latest/download/Genesis-Linux-x64.AppImage) |

Otras descargas (.msi, .rpm) y `SHA256SUMS.txt`: [última versión](https://github.com/UreckChan/genesis-app/releases/latest).

> **Instalación bajo su propio riesgo.** Genesis es un proyecto independiente y sus instaladores no
> llevan certificado comercial de editor, así que Windows y macOS mostrarán un aviso la primera vez.
> Descarga solo desde aquí y comprueba el archivo con `SHA256SUMS.txt`.
